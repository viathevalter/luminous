# Luminous Alley — Premium Redesign Brief

## Goal
Reposition Luminous Alley as an international industrial workforce partner for critical projects, with strong Oil & Gas / petrochemical positioning for UAE while retaining European operations.

## Core message
**We mobilize the people who keep industry moving.**

The site must not feel like a generic recruitment agency. It should feel like an international industrial workforce / engineering services company.

## Visual direction
- Fullscreen cinematic industrial imagery
- Deep navy / graphite / black
- Warm metallic amber accent
- Elegant serif headlines + clean sans-serif UI
- Workers shown in real industrial context, not smiling stock portraits
- Minimal cards, strong editorial layouts
- Motion with purpose, not decoration

## Homepage V1
1. Header + language switcher EN/PT/ES/IT
2. Scroll-controlled Hero
3. Sticky Workforce roles
4. Industries connected by a pipeline visual
5. UAE + Europe global presence
6. Premium CTA + footer

## Hero narrative
- Start: wide refinery/petrochemical complex, 3 Luminous workers in PPE
- Supervisor/foreman = coordination
- Pipefitter = technical execution
- Welder = specialization
- Scroll text beats: THE RIGHT PEOPLE → THE RIGHT SKILLS → READY TO MOBILIZE

## Responsive rule
Desktop gets the full scroll storytelling. Mobile must be faster and lighter: poster/video playback + normal content, no expensive frame sequence.

## Asset rule
Do not bake text into generated images/video. Logo on uniforms may be visual, but UI text, buttons and translations remain HTML.
